# Saveurs Maison — Application de recettes

Application PWA gratuite, installable sur Android et iPhone.

## Publier sur GitHub Pages
1. Créez un dépôt GitHub nommé : `votre-nom.github.io`
2. Téléversez tous les fichiers de ce dossier.
3. Allez dans `Settings` > `Pages`.
4. Choisissez `Deploy from a branch`, branche `main`, puis `Save`.
5. Ouvrez `https://votre-nom.github.io`

## Installer sur Android
Ouvrez le site dans Chrome, puis appuyez sur « Installer l’application ».

## Installer sur iPhone
Ouvrez le site dans Safari, appuyez sur « Partager », puis « Sur l’écran d’accueil ».

## Ajouter une recette
Dans `app.js`, copiez un bloc existant dans `recipes` et changez :
- `title`
- `category`
- `time`
- `level`
- `description`
- `ingredients`
- `steps`
